## Setting up the client

Download [False Hero](https://store.steampowered.com/app/2538870/False_Hero/) on Steam.

Right-click the game in your Steam library and select <b>Properties -> Game Versions & Betas</b>

Enter the following password to gain access to the archipelago build of the game: <b>ft2n89fwfhnwf92ne23f</b>

Once downloaded, you can create a new savefile and connect to your Archipelago world using the in-game console.

(Note: The archipelago does not support the room randomizer mode)

## Setting up the world

If you haven't installed it yet, download and install [Archipelago](https://github.com/ArchipelagoMW/Archipelago/releases/latest)

Download the [False Hero AP World](https://github.com/TorchlightGames/ArchipelagoFalseHero/releases) and double-click or move it to your custom_worlds folder to install it

Start Archipelago and use the <b>Options Creator</b> to create your yamls and put them into the <b>Players</b> folder.

Once all yamls from every participating player are collected, run <b>Generate</b> in the archipelago, which will output your .zip to the output folder.

Upload this zip to host your game on the [Archipelago website](https://archipelago.gg/uploads)

## Tracking the game

You can use the [Universal Tracker](https://github.com/FarisTheAncient/Archipelago/releases?q=Tracker) to track missing checks.

This only works, if you have the False Hero AP World & the tracked players yaml installed locally.
